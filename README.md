## Project Description: Fully Functional Calculator using HTML, CSS, and JS
This project is a fully functional calculator built using HTML, CSS, and JavaScript. The calculator mimics the look and feel of a standard digital calculator with a sleek, modern design.

### Features:
- Basic Arithmetic Operations: Supports addition (+), subtraction (-), multiplication (* via / button for division), and division operations.
- Clear and Delete Functions: Includes "AC" for clearing all inputs and "DEL" for deleting the last entry.
- Percentage Calculation: Supports percentage (%) calculations.
- Parentheses: Allows use of parentheses for grouping operations.
- Responsive Display: Shows the current input or result in a display area.
- User-Friendly Interface: Buttons are clearly labeled and visually distinct with a glowing effect on a dark background.

### Technologies Used:
- HTML: Structures the calculator layout.
- CSS: Styles the calculator with a modern look, including button glow effects and display area styling.
- JavaScript: Adds functionality to perform calculations, handle button presses, and update the display.

This calculator project is a great example of using front-end web technologies to create interactive tools that can be used in various applications or as a standalone web app.
